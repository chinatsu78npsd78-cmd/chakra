# ホリスティックフェイシャル 顔マップ

salonで使用する顔の反射区・顔筋肉・左右差・チャクラの確認用Webアプリです。

## 使い方

- `index.html` をブラウザで開くと、そのまま使用できます。
- 顔の色付きエリアまたは部位一覧を選ぶと、対応する見立てが表示されます。
- 「反射区／筋肉／左右差／チャクラ」で重ねる情報を切り替えられます。
- URLの末尾に選択状態が残るため、特定の部位を開いた状態で共有できます。

## 公開先

GitHub Pagesの `/chakra/face-map/` へ配置する想定です。

## 大切な位置づけ

顔の反射区やチャクラは医学的診断ではなく、心身をやさしく振り返るための象徴的な見立てとして扱います。
